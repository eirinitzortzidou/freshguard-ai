# Demo bundle

Small, versioned sample used by the hosted dashboard (see `docs/DEMO_DEPLOYMENT.md`).
Built by `scripts/build_demo_bundle.py`; `freshretailnet/manifest.json` lists the sampled
series, the git commit and the SHA-256 of every file.

Attribution: contains a derived sample of **FreshRetailNet-50K** by Dingdong-Inc
(<https://huggingface.co/datasets/Dingdong-Inc/FreshRetailNet-50K>), licensed under
CC BY 4.0 (<https://creativecommons.org/licenses/by/4.0/>). Changes: random subset of
series, daily aggregates, reconstructed demand and model outputs added.
