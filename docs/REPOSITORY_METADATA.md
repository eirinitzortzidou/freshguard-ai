**Short project summary** (for a profile README or pinned-repository caption):

> FreshGuard AI forecasts next-day demand for 50,000 fresh-food store-SKUs, corrects sales for
> stockouts and converts forecasts into profit-tuned orders. In a nested four-week backtest it
> cut next-day forecast error from 34.8% to 31.3% WAPE and raised simulated (hypothetical) profit
> against a tuned ordering rule in every week, with all assumptions, negative results and
> evaluation limits documented.
